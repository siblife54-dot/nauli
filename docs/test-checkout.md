# Тестовая покупка NAULI — 100 TRY

Временная кнопка «Тестовая оплата — 100 TRY» показывается только с единственным параметром `test_checkout=1`. Для обычных посетителей она скрыта. На экране возврата после оплаты тестовый блок также скрыт.

- Тестовая страница: `https://siblife54-dot.github.io/nauli/?test_checkout=1`
- Существующий тестовый Payment Link пользователя: `https://buy.stripe.com/test_dRm3cv2Yq6tK5ZSbstfMA00`
- Конфигурация: `assets/test-checkout-config.mjs`. Она не устанавливает сумму в Stripe: 100 TRY должны быть настроены в самом Payment Link.
- Три основных тарифа, цены и их Payment Links не меняются. Параметры URL не могут подменить ссылку кнопки. Валидатор разрешает только HTTPS-ссылку `buy.stripe.com/test_…`; live-ссылки не активируются.
- Это публичный переключатель для тестирования, не авторизация. Секретов и обращений к закрытым Stripe API в коде сайта нет.

## Адрес возврата в Stripe

У текущей тестовой ссылки возврат уже работает; менять его для этого теста не обязательно. Если настройки потребуется восстановить или перейти на явный plan:

1. В тестовой среде Stripe открыть именно существующий Payment Link на **100 TRY**.
2. Открыть **Edit → After the payment**, выбрать перенаправление на свой сайт (**Redirect to your website**).
3. В поле URL вставить буквально:

```text
https://siblife54-dot.github.io/nauli/?plan=temel&session_id={CHECKOUT_SESSION_ID}
```

4. Сохранить настройки тестовой ссылки. `{CHECKOUT_SESSION_ID}` не заменять вручную и не кодировать: Stripe подставляет уникальную Checkout Session после оформления. Не редактировать настоящие тарифы/ссылки и не включать live mode.

Документация: [Stripe — After a Payment Link payment](https://docs.stripe.com/payment-links/post-payment#change-confirmation-behavior).

## Как пройти покупку самостоятельно

1. Открыть тестовую страницу и нажать «Тестовая оплата — 100 TRY».
2. На Stripe Checkout убедиться, что отображаются тестовая среда и **100 TRY**.
3. Ввести email, тестовую карту **4242 4242 4242 4242**, будущий срок, например **12/34**, CVC **123** и имя. Нажать оплату. Реальные реквизиты для теста не использовать.
4. Дождаться возврата на сайт. В адресе должен появиться уникальный `session_id=cs_test_…`; экран показывает **NAULİ TEMEL PAKET**.
5. Нажать **Telegram'dan Erişim Al**, в Telegram нажать **Start / Başlat**. Боту передаётся весь ID без начального `cs_test_`.
6. BotHunter проверяет оплату `paid` через Stripe и выдаёт индивидуальную ссылку на закрытый канал. Открыть её и убедиться в получении доступа.

Тестовая карта и правила заполнения: [Stripe — Testing interactively](https://docs.stripe.com/testing#testing-interactively). Если оплата прошла, а приглашение не пришло, сохранить индивидуальный URL возврата для диагностики и не оплачивать повторно: переход и выдача доступа — разные этапы.
