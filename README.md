# NAULI

Новая шапка по готовому визуалу заказчика от 14 октября 2026 года.

Сайт: https://siblife54-dot.github.io/nauli/

## Текущая версия

Первое предоставленное изображение остаётся нетронутой основой шапки. По отдельному запросу пользователя добавлен пробный слой коррекции лица по оригинальной фотографии. Слой виден только в ограниченной области лица; все надписи, тело, одежда и оформление за этой областью показываются из исходного визуала. На смартфоне шапка занимает всю ширину экрана, на компьютере — колонку до 600 px по центру.

Сравнение лица крупным планом: https://siblife54-dot.github.io/nauli/compare/

Это проба сходства, а не гарантия фотографической идентичности. Исходная фотография доступна в сравнении.

## Откат

- Прежний вид без правки: https://siblife54-dot.github.io/nauli/?face=original
- Новый вид: https://siblife54-dot.github.io/nauli/?face=reference
- Чтобы вернуть прежний вид основным, изменить `DEFAULT_FACE` на `"original"` в `assets/face-choice.js`, увеличить `?v=` у ссылки на этот скрипт в `index.html`, сохранить и отправить изменение в `main`.
- Для полного возврата к состоянию до эксперимента сохранён и отправлен в GitHub тег `before-face-match-20261014` на коммит `c1d746559cd61e3f2980b3366e72c882f7fa33d9`. Не применять принудительный push: откатывать отдельным обычным коммитом.

Визуальная надпись «Получить» пока не подключена к форме или оплате: адрес назначения не задан. Над ней расположена отключённая HTML-кнопка. Все надписи продублированы семантическим HTML для экранных дикторов.

## Файлы

- `index.html` — единственная страница.
- `assets/style.css` — адаптивный размер шапки и область кнопки.
- `assets/nauli-hero-20261014.png` — первый визуал пользователя, 941 × 1672, сохранён без изменений.
- `assets/nauli-face-reference-v1.png` — результат пробной правки; на сайте показывается только лицо через альфа-маску.
- `assets/face-blend-v1.svg` — прозрачная маска с мягким краем, совместимая с Safari.
- `assets/face-choice.js` — выбор текущего и прежнего вида.
- `source/valeria-face-reference.png` — исходное фото лица для сравнения.
- `source/face-match-v1.md` — точный промпт, способ обработки и пути файлов.
- `compare/` — отдельная страница сравнения; элементы сравнения не добавлены в сам лендинг.
- `source/valeria-approved-20261014.png` — второе изображение пользователя для дальнейшей работы; на странице отдельно не загружается.
- `.nojekyll` — статическая публикация GitHub Pages.

Сейчас визуальные надписи являются частью готового изображения. Для их независимого редактирования потребуется отдельная задача по разделению макета на слои; скрытый HTML не меняет видимый текст.

Предыдущая реализация полностью удалена из текущего дерева файлов и доступна только в истории Git.

## Запуск и публикация

Для локального просмотра из корня репозитория: `python -m http.server 4174 --bind 127.0.0.1`.

GitHub Pages: ветка `main`, папка `/ (root)`. Пакеты, сборка и внешние сервисы не требуются.
