# NAULİ

Рабочая версия лендинга Валерии: сейчас сайт состоит только из согласованной шапки. Вёрстка, композиция и фотография перенесены без изменений из опубликованной версии.

Текущий сайт: https://nauli-valeria.jammy-siren-1357.chatgpt.site/

## Локальный запуск

Из корня репозитория:

```sh
python -m http.server 4174 --bind 127.0.0.1 --directory dist
```

Открыть http://127.0.0.1:4174/. На Windows вместо `python` можно использовать `py`.

Зависимости и установка пакетов для просмотра не нужны. `dist/` — готовые статические файлы сайта.

## Где редактировать

- `scripts/install-approved-hero.py` — HTML-шаблон шапки. Генерирует одинаковые страницы `/` и `/facecontrol/`.
- `dist/assets/valeria-approved-hero.css` — размеры, расположение и оформление элементов.
- `dist/assets/` — семь используемых ресурсов: фон, оформление, фотография и SVG-маски.
- `source/black-outfit-portrait/` — исходная фотография Валерии в sRGB, контуры и описание обработки.

После изменения HTML-шаблона:

```sh
python scripts/install-approved-hero.py
```

Проверка ссылок на ресурсы (Node.js 22 или новее):

```sh
node scripts/verify.mjs
```

Страница адаптируется под ширину экрана; приоритет — мобильные устройства. Не менять лицо, фигуру и пропорции Валерии. Тексты внутри декоративных изображений пока сохранены из утверждённого макета; дальнейшие изменения делаем поэлементно.

Кнопка «Получить» пока без перехода: её назначение добавим вместе со следующими блоками.

## GitHub и публикация

Основной репозиторий: https://github.com/siblife54-dot/nauli, ветка `main`.

Для хостинга используется содержимое `dist/`. Этот перенос сохраняет текущий адрес сайта; автоматическая публикация из GitHub пока не настроена. При дальнейшей работе изменения сохраняем в этом репозитории, публикацию выполняем отдельно.

Исходная копия Face Control и предыдущие варианты сохранены отдельно и не входят в рабочую версию.
