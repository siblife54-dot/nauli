# Работа над NAULİ

- Приоритет — мобильная версия для переходов из Instagram.
- Сейчас работаем только над шапкой; следующие блоки добавлять по запросу пользователя.
- Сохранять утверждённую композицию и оформление при точечных изменениях.
- Валерия должна оставаться собой: не менять лицо, фигуру, пропорции, позу и черты внешности. Не заменять фотографию сгенерированным портретом и не реконструировать детали лица.
- Текущая фотография находится в `source/black-outfit-portrait/approved-srgb-original.png`. Использовать корректный sRGB-профиль и сохранять оригинальные детали. Мягкость края выреза задаётся маской, а не размытием фотографии.
- HTML редактировать в `scripts/install-approved-hero.py`; затем запускать его для обновления корневого `index.html` и обеих страниц в `dist/`.
- CSS редактировать в `dist/assets/valeria-approved-hero.css`. После правки запускать генератор HTML, чтобы обновить хеш CSS в ссылке.
- После правок запускать `node scripts/verify.mjs`. Изменения композиции проверять в мобильном браузере.
- GitHub Pages публикуется из `main`, папка `/ (root)`. Сохранять корневой `index.html`, `.nojekyll` и относительные пути ресурсов; проверять работу с префиксом `/nauli/`.
- Не добавлять нижние блоки, меню, платёжные формы или внешние скрипты без задачи пользователя.
